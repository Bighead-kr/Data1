# 요양·실버시설 창업 입지/수요 분석 — 시군구별 장기요양시설 수급 갭 지도

국민건강보험공단·통계청 공공데이터를 결합해 시군구 단위로 "고령인구 대비 장기요양기관 정원"의 수급 갭을 계산하고, Tableau 지도로 시각화한 데이터 분석 포트폴리오 프로젝트입니다.

## 문제 인식

요양·실버시설 창업을 고려하는 예비 창업자는 "어느 지역에 시설이 부족한가"를 판단할 근거가 마땅치 않습니다. 인허가 통계나 시설 목록은 공개되어 있지만, 이를 지역별 고령인구 수요와 견주어 "공급 갭"으로 정리해 보여주는 자료는 찾기 어렵습니다. 이 프로젝트는 공공데이터만으로 그 갭을 계산하고 지도로 시각화해, 창업 입지 판단에 쓸 수 있는 1차 스크리닝 자료를 만드는 것을 목표로 합니다.

## 데이터 소스

| 데이터셋 | 제공 기관 | 비고 |
|---|---|---|
| 장기요양기관 시설별 현황(일반현황·입소인원) | 국민건강보험공단 | 30,595 / 43,581행. 입소시설(A01~A05, AAA)만 정원 집계에 사용, 재가서비스(B*/C*)는 제외 |
| 행정구역코드 | 통계청 | 2/5/8자리 계층형, 3,841행. 지역 결합 키로 사용 |
| 65세 이상 인구총조사 | 통계청(KOSIS) | 시군구별 고령인구·전체인구, 248행 |

원본 데이터는 `data/raw/`, 정제된 결과물은 `data/processed/`에 저장하며 둘 다 git 추적 대상에서 제외했습니다(용량·재현성 문제로 코드만 커밋).

## 파이프라인 구조

```
collect (원본 CSV 로드·검증)
  → clean (지역코드 정규화, 시설/인구 데이터 정제)
    → analyze (수급 갭 지표 계산)
      → visualize (Tableau 지도)
```

- **지역 결합 키**: 건강보험공단 파일의 시군구코드와 통계청 5자리 코드는 서로 다른 체계라 숫자로 직접 join하면 틀린 지역에 매칭됩니다. 대신 "시도명+시군구명" 텍스트를 정규화한 키로 매칭하고, 최종 `region_code`는 통계청 5자리 코드를 사용합니다(`src/clean/region_mapper.py`).
- **수급 갭 지표**: 시군구별 `capacity_per_1000_elderly`(고령인구 1,000명당 장기요양시설 정원)를 계산하고, 값이 낮을수록(공급이 부족할수록) 순위가 앞서는 `gap_rank`를 부여합니다(`src/analyze/gap_index.py`).
- **좌표 보강**: Tableau 지도 시각화를 위해 시군구 중심좌표(위도/경도)를 별도 공개 데이터셋에서 가져와 결합했습니다. 원본이 도(道) 명칭 개편(강원·전북 특별자치도) 이전 데이터라 발생하는 지역명 불일치는 별칭 테이블로 보정했습니다(`src/clean/region_coords.py`).
- 전 구간 pytest로 검증(TDD): `pytest -v`

## AI 협업 방식

이 프로젝트는 Claude Code와 함께 TDD 기반으로 진행했습니다. 데이터 파싱·지역코드 매핑·수급 갭 계산 같은 코드 작업은 실패하는 테스트를 먼저 작성하고 최소 구현으로 통과시키는 방식으로, 데이터 수집·Tableau 시각화처럼 단위 테스트가 어려운 작업은 행 수 확인·스모크 테스트·화면 검증으로 대체해 진행했습니다. 구현 계획은 `docs/superpowers/plans/2026-08-25-elderly-care-siting-saas.md`에 태스크 단위로 기록되어 있습니다.

## 실행 방법

```bash
pip install -r requirements.txt  # pandas, openpyxl, pytest
pytest -v                        # 전체 테스트 실행
python3 -c "from src.pipeline import run_pipeline; run_pipeline('data/raw', 'data/processed')"
```

`data/raw/`에는 국민건강보험공단·통계청에서 수동으로 받은 원본 CSV(및 시군구 중심좌표 원본)가 있어야 합니다. 실행 결과는 `data/processed/gap_index.csv`로 저장됩니다.
